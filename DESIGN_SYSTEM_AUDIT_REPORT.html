Empirical Finding: Design Token Bypassing & Variant Explosion

While the project possesses a well-crafted foundational design specification in DESIGN_SYSTEM.md with 13 core tokens and a strict boxy NYC.gov identity, subsequent feature implementations (Lapor Insiden, Bug Hunter dashboard, Contact forms, and Admin CRUD) bypassed global tokens in favor of scoped <style> blocks and inline styling.

This has generated 106 unique color values (47 near-duplicate pairs), 36 font sizes (including fractional sizes like 10.5px and 12.5px), 18 non-grid orphan spacing values (used 320+ times), 14 layout breakpoints, and 25 distinct button class implementations doing essentially identical jobs.
